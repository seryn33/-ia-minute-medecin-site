# L'IA Minute du Médecin — Ressources compagnon

Les 16 ressources web du livre *L'IA Minute du Médecin* (Dr Guillaume Zagury et Samuel De Queiroz, Éditions Medicilline), servies sur medecin.prompt-id.com. Chaque page correspond à une double page du livre et est ouverte par le QR code imprimé.

**Important : ne jamais renommer les fichiers HTML** — leurs URL sont gravées dans les QR codes du livre imprimé. Le contenu des pages, lui, peut être mis à jour librement.
